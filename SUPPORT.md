# Support

## I have a question about using AI Friend

Start with [README.md](README.md) — the one-command quick start, the
architecture overview, and the configuration reference all live there.
`docs/` has deeper operational guides (`docs/ARCHITECTURE.md`,
`docs/BRINGING_IT_TO_LIFE.md`). If that doesn't answer it, ask in
[GitHub Discussions](https://github.com/PALabs-v1/AI_friend/discussions).

There is no hosted documentation site yet — everything lives in the repo
itself, so a search in `docs/` or `.agents/CONTEXT.md` (the engineering
ledger — what was actually built and measured, not just what was intended)
usually finds the real answer faster than asking.

## I found a bug

[Open an issue](https://github.com/PALabs-v1/AI_friend/issues/new/choose)
using the bug report template. Include your OS, which launch mode you used
(`light`/`heavy`/`full`, `--vision` or not), and whether Ollama is running
host-native or containerized — see the template for the full checklist.

## I have a feature idea

Same place: [open an issue](https://github.com/PALabs-v1/AI_friend/issues/new/choose)
with the feature request template, or start a
[Discussion](https://github.com/PALabs-v1/AI_friend/discussions) first if
it's more of an open question than a concrete proposal.

## I found a security vulnerability

Do **not** open a public issue. See [SECURITY.md](SECURITY.md) for the
private reporting process.

## I want to contribute code

See [CONTRIBUTING.md](CONTRIBUTING.md) for the workflow and verification
bar, and [CLAUDE.md](CLAUDE.md) for an architecture tour written for
whoever's actually going to touch the code next.

## Response times

This is currently a single-maintainer project (see
[MAINTAINERS.md](MAINTAINERS.md) / [GOVERNANCE.md](GOVERNANCE.md)). There's
no SLA — security reports get priority per `SECURITY.md`'s acknowledgement
target; everything else is best-effort.
