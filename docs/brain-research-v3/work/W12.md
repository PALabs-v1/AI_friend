# W12: neuroscience fidelity and human-data probes

Owns (see `COVERAGE.md`): the fidelity audit itself
(`research/neuro/fidelity-table.md` and `research/neuro/verification-log.md`,
summarized in `12-neuroscience-grounding.md`), the `NF-*` findings that no
other workstream owns (currently `NF-38`, global workspace), and the
human-data probe suite.

Starts now, alongside wave A's benchmark: the audit and the probes need no
other workstream. Fixes that belong to another workstream's mechanism (W1
reconsolidation, W2 affect timescales, W3 trust learning, W7 base-level
learning) are built there; W12 supplies their probes and the published
formula to test against.

## Problem

The brain borrows names from cognitive science and neuroscience (ACT-R,
appraisal, dopamine, cortisol, global workspace), but nothing checked the
borrowed mechanisms against the models they are named after, or the system
against human behavior. Two are already known to deviate from their own stated
models (`12-neuroscience-grounding.md`, Audit):

- the ACT-R base level uses only the use count and the last use, so a spacing
  effect is impossible by construction;
- novelty is word overlap with a short window, with no long-term familiarity,
  consistent with the baseline's inverted novelty (repeated 0.75 vs fresh 0.63
  at 1y).

Aniket, 2026-09-26: "the formula and the system and all we are using compare
with the actual design those neuroscience modulations are designed to, our
code may be not correct, we have to make those updates".

## Deliverables

1. **Fidelity audit — done.** Every mechanism named after, or clearly derived
   from, a published model, in `research/neuro/fidelity-table.md`: file:line
   (verified), the model it names or implies with a verified citation, the
   model's published form where one exists, what the code does, a deviation
   (bug / deliberate simplification / label-only / dead code), a concrete
   correction, its flag, its pinned-test requirement, its BrainBench arm and
   prediction, and an owning workstream. 39 rows (`NF-1`..`NF-39`); every
   citation checked at its source in `research/neuro/verification-log.md`
   (63 verified, 24 partly, 2 not verified — see that log for which two and
   why). Each row has a `COVERAGE.md` owner.
2. **Corrections.** For each `NF-n` owned here:
   - the corrected formula behind a switchboard flag (`NEURO_<NAME>_ENABLED`,
     default off until acceptance);
   - a unit test that pins the published formula on worked values from the
     source, and fails on the old code;
   - a BrainBench arm comparing flag off and flag on against the V2 baseline
     grid for the suites the mechanism reaches.

   A `label only` item is either made real (the code starts meaning the name)
   or renamed; P10 applies the rename.
3. **Human-data probe suite**: a `humanlike` suite in BrainBench,
   `architecture_only`, driving the real components with controlled stimuli
   (the way the human experiments do; natural lifesim timelines cannot isolate
   spacing or serial position). Probes and pass shapes are in
   `12-neuroscience-grounding.md`:
   - `forgetting_curve`
   - `spacing`
   - `serial_position` (report only)
   - `habituation`
   - `mood_inertia`
   - `trust_asymmetry` (a model comparison — RW vs Bayesian-volatility vs
     current — not a fixed `abs(loss) > gain` pass condition; Duncan et al.
     2026 found no significant overall asymmetry across 68 trust-game
     studies, so the probe stratifies rather than asserts a universal law)

   Personas and seeds come from lifesim's dev split so results pool like the
   other suites; stimuli are generated per seed.
4. **Before picture.** The probe suite run on the V2 application code and on
   wave A, written into `12-neuroscience-grounding.md`, before any correction
   lands. A probe that cannot fail on today's code is redesigned.

## Acceptance (mechanical)

- Every `NF-n` has a verdict, an owner, and a status
  (`test_every_nf_finding_is_owned`, `test_no_row_names_an_id_that_does_not_exist`
  in `test_brain_v3_coverage.py`). Still open: a drift test that fails if a
  new mechanism naming a published model lands in `app/` or `crates/` with no
  matching fidelity-table row — the initial audit was a search across author
  and model-name strings plus manual code reading, not one fixed grep, so
  this needs its own design before it can be mechanical.
- A correction is adopted (flag on by default) only if `compare` flag-off vs
  flag-on on its suites shows no significant regression in any metric after
  Holm, and the probe it targets moves to its pass shape. Otherwise it stays
  off, and the grounding document records why.
- The probe suite's own tests prove each probe fails on a deliberately broken
  component (for example `spacing` fails on a base level that ignores use
  history), so a pass is evidence.
- `tests/test_brainbench_gates.py` passes; gate bands for `humanlike` are
  added once the V2 before-picture exists.
- Every citation in `12-neuroscience-grounding.md` verified against a real
  source (verification log).

## Constraints

- No hosted LLM APIs; `architecture_only` for every probe that the mechanism
  allows.
- DR-007 and DR-034 (forgetting never deletes; emotional memories fade very
  slowly with no floor) bind the forgetting corrections.
- The W1 and W3 tournaments decide between the neuro variant and the others;
  W12 does not preempt them.
