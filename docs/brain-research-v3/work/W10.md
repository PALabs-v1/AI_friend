# W10: security

Owns (see `COVERAGE.md`): S-2, C0-1, C0-3, DR-032. You are the attacker
first and the fixer second: find what breaks, prove it with a failing test,
then fix it.

Two parts, because two items depend on other workstreams:
- **W10a** (now): items 1-7 below.
- **W10b** (after W9 lands, and for item 9 after W2): items 8-9. They touch
  `subconscious_agent.py` and affect mechanics that W9 and W2 are changing.

## W10a

1. **Stored-injection corpus against retrieval -> prompt.**
   - A corpus under `backend/evals/security/` of at least 50 injection
     payloads across families. Families:
     - instruction override
     - role/delimiter spoofing (including forged `[RETRIEVED-CONTENT]`
       markers)
     - prompt-template echo
     - unicode confusables and zero-width characters
     - markdown and HTML smuggling
     - tool/JSON-shaped payloads
     - very long payloads
     - payloads split across two memories that only combine when both are
       retrieved
   - Store each through the real `MemoryStore.add_memory`, retrieve through
     the real turn path, and assert on the exact prompt text the model would
     receive: payloads quarantined by `AntiInjectionGate` and delimiters,
     never at system level, and never able to close or forge the delimiter.
   - Cover every path that puts memory text into a prompt:
     - chat
     - proactive (S-1 was fixed there; prove it still holds)
     - reflection / consolidation
     - surfacing
     - System2 appraisal
     - identity / persona prompt
     Find them all by grep, and list them.
2. **S-2**: retrieved-memory sanitisation runs regardless of
   `MEMORY_TRUTH_ENABLED`. Regression test runs with the flag off.
3. **Graph poisoning via reflection triplets.** Construct reflection output
   whose triplets try to create entities or edges that later inject into
   prompts or distort retrieval (entity names carrying payloads, edges to
   protected persona fields, cycles, enormous fan-out). Show what production
   does with each, then fix what is unsafe.
4. **Malformed metadata fuzzing.** `hypothesis` over memory rows and
   metadata (wrong types, NaN/inf, huge values, missing fields, unparsable
   timestamps, wrong embedding dimensions, deep JSON) through write, read,
   search and consolidation. No crash, no silent corruption, and errors
   surface through the paths production already uses (`last_search_error`
   and friends).
5. **Unsafe deserialization audit.** Every `pickle`, `yaml.load`, `eval`,
   `exec`, `json` of untrusted input into code paths, `marshal`,
   `torch.load` and `numpy.load(allow_pickle=True)` in `backend/`. List each
   with a verdict and a fix or a written justification.
6. **C0-1, LiveKit `network_mode: host`** (`docker-compose.infra.yml` ~100)
   bypasses the loopback-only port policy, and `mesh-integrity.yml` cannot
   see it.
   - Fix the exposure: bind LiveKit's signalling and RTC to loopback, or
     document precisely why media needs a wider bind and restrict it to that.
   - Extend the mesh-integrity check so host-network services are checked
     too.
   - Test the check against a fixture compose file.
7. **C0-3, NATS without auth by default.**
   - Make authenticated NATS the default for the mesh. `nats-accounts.conf`
     already documents the opt-in, and `.env.example` defines per-agent
     users.
   - Every agent connects with its credentials.
   - Dev bootstrap generates them.
   - A mesh started with the default config refuses an unauthenticated
     client (test).
   - Keep tests and local dev working, and say exactly what a developer has
     to do differently (the report lists restart and config steps, including
     any that need `sudo`, for Aniket to run).
