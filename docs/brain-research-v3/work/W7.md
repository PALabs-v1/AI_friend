# W7: consolidation, forgetting and growth

Owns (see `COVERAGE.md`): F-007, F-014.1, DR-007, DR-034.
Also owns the neuroscience fidelity findings `NF-3` (spacing bonus mislabeled
Pavlik & Anderson) and `NF-5` (consolidation/replay mislabeled CLS/sleep
replay) — `research/neuro/fidelity-table.md`, synthesis in
`12-neuroscience-grounding.md`.

Wave C, after W1 (consolidated facts must respect W1's supersession) and P8
(growth at scale).

## Problem

- **F-007.** Throttled or concurrent reflection drops episodes instead of
  deferring them.
- **F-014.1.** `workspace_transitions` gains one row per turn and nothing
  prunes it (10 -> 223 over 6 months, 1 row per turn).
- **Growth.** Memory grows about one row and one vector per turn with no
  abstraction: 10 years is 40-150k turns per persona.
- **DR-007 / DR-034.** Forgetting is not implemented as decided:
  - trivia should decay toward unretrievable, never deleted
  - emotional memories resist decay but are not boosted in unrelated
    retrieval, and even they fade eventually, very slowly, with no
    permanent floor

## Deliverables

1. **F-007**: reflection that cannot run now defers its episodes (a durable
   pending queue with bounded retries) and never drops them. Regression
   test with concurrent and throttled reflection. Coordinate with W8's M-13
   (store failure handling) rather than duplicating it.
2. **Semantic consolidation**, behind switchboard flag
   `MEMORY_SEMANTIC_CONSOLIDATION_ENABLED` (BrainBench arm `+consolidation`):
   - Repeated episodic memories become semantic abstractions ("usually
     drinks black coffee"), with links to their source episodes, which are
     kept.
   - An abstraction respects W1's validity windows: a superseded preference
     is not re-asserted by an old abstraction.
   - The consolidation content is LLM-produced (DR-037), so it is measured
     `llm_augmented`.
3. **Forgetting** (DR-007, DR-034):
   - retrievability decay by memory class (trivia fast, ordinary medium,
     emotional slow with no permanent floor)
   - no deletion
   - emotional salience does not boost retrieval for unrelated queries (the
     V2-rejected rumination failure mode)
   Decay constants go in `Config`, with the reasoning.
4. **F-014.1**: `workspace_transitions` retention (bounded window or
   compaction), and a test that growth is bounded over a simulated year.
5. **Growth curves over 10 years**: resources suite plus memory suite at
   `1y`, `3y` and `10y` (panel subset, `llm_augmented` on home-gpu for
   memory content; `architecture_only` for structure growth). Report rows,
   vectors, DB bytes and latency vs simulated time, with and without
   consolidation.

## Acceptance (mechanical)

Adopt consolidation only if both hold:
- `compare` baseline vs `+consolidation` on the memory suite: no significant
  regression in any category after Holm, and an improvement in at least one
  of `current`, `stale_trap` or trivia-forgetting.
- Memory growth per simulated year measurably lower, OR retrieval quality
  higher at equal growth.

Otherwise it stays off, and the ADR records why.

Also:
- Forgetting:
  - `trivia_recent` recall stays high while old trivia's retrievability
    falls
  - emotional memories outlast ordinary ones but still fade over the 10y
    horizon
  - a property test proves no row is ever deleted
- F-007: zero dropped episodes under a concurrency and throttle test.
- `workspace_transitions` bounded, and `resources.workspace_transitions_per_turn`
  in the gate drops (better direction).
- `tests/test_brainbench_gates.py` passes.
- ADR `docs/brain-research-v3/adr/ADR-W7-consolidation.md`, and F-007 /
  F-014 status updates.
