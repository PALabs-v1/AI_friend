# Neuroscience fidelity table

**Neuroscience proposes, BrainBench decides.** This is a computational/behavioral audit, not a claim that scalar software state is a neuron, hormone, or human feeling. “Published form” reports equations only where a source actually gives one; otherwise it states that the source is conceptual. Corrections are proposals, not implemented changes. Every correction is behind a `NEURO_<NAME>_ENABLED` flag, default `off`; adoption requires a passing pre-registered BrainBench comparison. A correction is not implementation-ready until its unit test pins the published equation to a worked numeric example verified in the cited paper. Where no such example was located, the row says so and the correction remains blocked; a locally constructed fixture is explicitly not a substitute.

Priority: P0 means a defect against the mechanism's own stated behavior touches a measured system problem; P1 is a model/code defect; P2 is label-only or cosmetic mismatch; P3 is dead/unwired code. Workstream owners: W1 memory truth, W2 affect, W3 trust, W7 consolidation, W8 metacognition, W9 proactive/goals, W12 fidelity/probes.

## Competing models: which arm runs first

- **Memory accessibility:** test ACT-R full trace sum first because it is the closest exact correction to the currently named BLL and can be pinned algebraically; compare the optimized ACT-R approximation as a storage tradeoff. Test Pavlik–Anderson separately after fitting task parameters; it is a distinct spacing model, not a synonym for ACT-R optimized learning. Forgetting curve families (power vs exponential/log/root forms) remain empirical competitors; no universal function is presumed.
- **Contradictory evidence:** test W1 temporal versioning/supersession against a latent-cause/context-retention arm. Fear-conditioning reconsolidation papers motivate a gated hypothesis but do not settle autobiographical memory updates.
- **Trust:** run RW social prediction error and Bayesian volatility-aware learning as separate W3 arms. Do not pre-register `|loss|>gain` as a general human law: Slovic’s evidence is public risk management, and the repeated-trust-game meta-analysis by Duncan et al. (2026, [DOI](https://doi.org/10.1111/bjop.70045)) finds trust learning depends on reciprocation and tested priors, with no overall prior-by-reciprocation interaction in its full sample.
- **Affect dynamics:** compare current deterministic reducer, elapsed-time OU-like mean reversion, and two-timescale event/mood state. Russell’s core-affect account does not itself specify a fast/slow numerical filter; the dynamics are an engineering prediction tested against fixed-interval observations.

## Ranked order of work

1. **NF-23 trust evidence path (P0):** neutral-turn credit and ceiling erase the ability to react to harm; fix evidence attribution and preserve uncertainty before tuning asymmetry.
2. **NF-39 familiarity and novelty (P0):** measured repeated/fresh ordering is inverted. Instrument per-antecedent history first, then test semantic familiarity with exposure recovery.
3. **NF-12 user/event appraisal (P0):** current mood is fed back as appraisal; a user’s positive or negative turn cannot reliably move valence in the measured direction.
4. **NF-17 arousal/resource separation (P0):** derived fatigue/adrenaline arousal can be written into persistent energy, producing state contamination.
5. **NF-16 elapsed-time affect evolution (P0):** nominal tick duration makes equal elapsed intervals diverge under delayed/missed ticks; Rust/Python behavior also differs.
6. **NF-6 temporal contradiction wiring (P3 status, high product rank):** memory truth is a measured system problem; a store being constructed is not evidence it participates in retrieval or writes.
7. **NF-2 successful retrieval reference bookkeeping:** ACT-R’s reference history cannot be corrected until actual successful retrievals are recorded and candidate exposure is separated.
8. **NF-1 default base-level correction:** the default history score is neither full nor optimized ACT-R; compare exact BLL with storage cost and the hybrid ranker intact.
9. **NF-30 proactive outcome handling:** distinguish silence from dismissal and keep user contact limits hard; the learned re-raise rule is a hypothesis, not a permission model.
10. **NF-4 archive/retention policy:** keep archive TTL separate from activation and honor DR-007 source preservation.
