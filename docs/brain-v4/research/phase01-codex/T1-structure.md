# T1 — Layers, loops, and what “closed” means

## 1. Bottom line

There is no empirically established three-layer human mind that software should reproduce. Reactive, deliberative and reflective are useful descriptions of **processing timescales and control paths**, but they are not cleanly separate brain modules. Leading cognitive architectures organize around cycles, shared working state, memories, goals and action selection; they allow fast learned responses and slower reasoning to cooperate. BDI architectures make commitment and goal management explicit. CLARION explicitly separates implicit/explicit processing and includes motivation and metacognition. LIDA implements a competitive workspace broadcast. Soar and ACT-R make memory, procedural knowledge and decision cycles computationally inspectable. None supplies a universally accepted, complete blueprint for mind.

For this project, the owner’s **loop is the better top-level engineering frame** because it gives an observable route from event to state update to chosen behavior to learning. But the current linear “perceive, appraise, remember, feel, decide, act, reflect” sequence is still too simple: memory retrieval must precede and shape appraisal/decision; action outcomes must feed learning; and concurrent/background changes need explicit ordering and provenance. The best candidate is a **state-and-control architecture**: one authoritative, typed agent state; event-driven fast and slow control lanes; and an explicit, versioned transition graph connecting perception, retrieval, appraisal, candidate selection, action, outcome and consolidation. Identity is a set of cross-cutting constraints and slow variables in that graph, not a fourth processing stage.

In the live code, a foreground path already runs perception → appraisal → state update → decision → action → reflection trigger. Several important state-to-behavior paths are real: mood/state informs the next decision and response prompt; surfaced memories ground responses; the persona prompt and policy constrain generation. Yet these are not one validated, closed causal loop. The dream and “inner monologue” labels overstate their role: a dream is generated from three random graph entities and logged without persistence, while monologue text is published to `state.subconscious` with no application consumer found. Conversely, reflection and memory consolidation do write persistent facts that can later be retrieved. Persona drift, however, is gated by a review queue that defaults to required and has no production approval caller found in the permitted code scan.

The test for “closer to a mind” should therefore be **causal behavioral continuity**, not more internal nouns or hours of background generation: a named state must persist across a defined interval, be changed by evidence, produce a predicted later action difference when experimentally intervened on, and have a trace that links the evidence, state transition and behavior. Passing that test supports a claim about an engineered closed loop. It cannot settle subjective experience; that remains `UNKNOWABLE` under the project’s working target.

## 2. Evidence

### How established architectures carve processing

| Architecture | Organization of fast / slow processing | Memory, motivation, affect, self | Implementation and what evaluation establishes |
|---|---|---|---|
| **Soar** | Repeated decision cycles match productions, propose and select operators, apply them, and create substates on impasses. Reactive behavior emerges from learned productions; deliberation can search or decompose a problem; chunking compiles solved impasses into future procedures. The architecture is a cycle with multiple depths, not three stacked tiers. | Working, procedural, semantic and episodic memory are distinct. Goals are explicit states/operators. Emotion appraisal and reinforcement learning are architectural additions. “Self” is representable in working/semantic state, not a privileged identity organ. | A running, research-developed architecture with agents and task evaluations. The Soar 9.6 overview documents decision making, impasses, chunking, reinforcement learning, semantic/episodic memory and agent examples; task success demonstrates capability in a task, not general human-level cognition [1]. |
| **ACT-R** | A hybrid architecture with modules and buffers coordinated by production rules. Fast production selection/retrieval and slower sequential cognition share a common cycle and timing constraints; this is not a reactive/deliberative/reflective partition. | Declarative and procedural memory, goal/imaginal/visual/auditory modules, and utility/activation mechanisms. The 2019 review describes emotion and physiology as future extensions, so affect is less central than memory and cognition in standard ACT-R. Self-model is generally task-specific knowledge and goals. | Implemented as a program and used to fit/predict human behavior in basic and applied work; strongest evidence is domain- and task-specific model fit, not one integrated autonomous personality [2]. |
| **LIDA / global workspace implementations** | A cycle: construct/update a current situation model, form attention coalitions, compete for a limited workspace, broadcast the winner, then select action and learn. This is the closest architecture in the set to a workspace-based integration story. The broadcast is a proposed access mechanism; calling it consciousness does not establish subjective experience. | Working situation, perceptual, episodic, declarative and procedural memories; attention and action schemes; affect/salience can influence competition. Self-model is an implementation-dependent content, not guaranteed by the workspace. | LIDA has a computational framework and implemented agents, but its own 2016 tutorial distinguishes the broader conceptual model from the subset computationally implemented. It is useful as an integration hypothesis, not evidence that a software workspace reproduces human consciousness [3]. |
| **CLARION** | Four interacting subsystems: action-centered (ACS), non-action-centered (NACS), motivational (MS), and metacognitive (MCS). Each has implicit and explicit levels, giving it a concrete account of quick learned responses alongside explicit reasoning. | ACS procedural skills, NACS declarative/reasoning, MS drives/goals, MCS regulation. This offers a richer motivation and control account than a bare three-tier stack; self/identity still needs a model of persistent self-relevant beliefs. | Implemented and evaluated on cognitive tasks and, in a 2025 robotic study, a stress-inspired internal variable modulating deliberation. In the robot task, a single table-clearing run took six minutes and stopped after six actions; the simulated comparison ran 100 task episodes per condition. This is a narrow proof of state-dependent action selection, not human-like affect [4]. |
| **BDI** | An interpreter updates beliefs from events, generates applicable plans, deliberates over goals/desires, commits to intentions and executes their steps; reactive events and longer commitments can coexist. The engineering strength is explicit intention scheduling and commitment, not a cognitive theory of every process. | Beliefs include the world, others and the agent; desires/goals specify preferred states; intentions are commitments; plan libraries encode means. Affect, episodic memory and identity are optional extensions. | Maturely implemented in agent programming languages and used in multi-agent systems. A 2020 survey documents variants and tradeoffs, including intention conflicts and scheduling costs. It supports explicit agency/control design, not psychological completeness [5]. |
| **Predictive processing / active inference** | A hierarchical generative model predicts sensory input; inference updates beliefs, while policy selection chooses actions partly to obtain preferred or informative future observations. Timescale hierarchy and motivational precision can be modeled, but it is not one settled executable architecture. | Beliefs and preferences/goals are integrated; salience/precision modulates inference and control. A self can be represented as a latent model of body/agent-world coupling, but there is no agreed complete agent implementation for identity. | Active inference is a mathematical and computational modeling framework applied to tasks and empirical data. The review emphasizes that predictive processing is a broad family and active inference a specific planning/decision framework; evidence for a model fit is not evidence for a complete mind theory [6]. |

These architectures share a practical lesson: **use interacting mechanisms with named state, not a single narrative pipeline**. They disagree on what is fundamental: production systems and procedural learning (Soar/ACT-R), access competition and broadcast (LIDA), implicit/explicit dual processing plus motivation (CLARION), commitment semantics (BDI), or generative prediction and policy inference (active inference). Their successful implementations are real but scoped. Their evaluations usually establish task behavior or human-data fit, not broad claims about identity or consciousness.

### LLM agents and what they leave out

**Generative Agents** combine an observation/memory stream, retrieval, reflection summaries and planning in a simulated town. In the Smallville demonstration, 25 agents coordinated a party over two simulated days. In a separate believability comparison, 100 participant rank sets across five conditions favored the full architecture; removing observation, planning or reflection reduced ratings, and full versus the prior-work baseline was reported as Cohen’s *d* = 8.16. This is evidence that memory/planning/reflection can change judged believability in this setup; it does not isolate long-lived identity from prompt effects, prove causality outside the ablation, or demonstrate real relationships [7].

**MemGPT** treats model context as a limited fast-memory tier and external storage as slower memory; tool calls move material between tiers and manage control flow. It evaluated long-document analysis and multi-session chat, showing a practical memory hierarchy, not an affective or reflective architecture [8]. **CoALA** provides a useful neutral description of LLM agents: modular memories, internal (retrieve/reason/learn) and external actions, and a repeated decision cycle. It is a framework for comparing systems, not a system with an independent cognitive-efficacy score [9].

Newer work shifts from “retrieve more text” toward explicit memory maintenance and evaluation. **MemoryAgentBench** (2025) separates accurate retrieval, test-time learning, long-range understanding and selective forgetting; the paper reports current methods do not master all four. Its contribution is an incremental multi-turn benchmark, not evidence of a single best memory architecture [10]. **Infini Memory** (June 2026 preprint) stages observations, consolidates them into topic documents, and iteratively inspects them at retrieval time; its abstract reports 64.7% overall on MemoryAgentBench and complementary gains from topic maintenance and iterative inspection. That score is only comparable under the paper’s own benchmark/model protocol and should not be read as a general mind measure [11].

Two cautionary 2025–26 results directly matter to this project. Xiong et al. report controlled memory add/delete experiments where selective addition plus deletion improved performance by an average absolute 10% over naive growth on their tested agent tasks, while errors and stale demonstrations propagated through retrieval [12]. A 2026 preprint, **AfterDeleteBench**, reports that with Qwen2.5-7B-Instruct and synthetic secrets, one query recovered a deleted secret in roughly two-thirds of exposed-then-deleted cases and zero matched never-exposed controls; it further reports 62–99% exact reconstruction across Qwen, Mistral and Phi-3 when secret components remained in separate records. These are bounded synthetic tests, but they show why “record deleted” is not equivalent to “state’s causal influence removed” [13].

These systems leave out or under-specify the parts that matter for this brief: an auditable affective state with calibrated dynamics; a slow, bounded self-model distinct from prompt text; stable commitments and motivations that cause autonomous but interruptible behavior; and causal evidence that a memory or state update changes behavior as intended over time. Most report answer accuracy, task success, retrieval, or human-rated believability. Those metrics are useful but not interchangeable.

### The two proposed frames

**Layers with identity across them** helps name latency classes and keep fast control responsive. It hides memory/state ownership, the direction of information flow, how layers arbitrate, how one state persists across turns, and how background updates become foreground behavior. “Identity runs across them” risks becoming an untestable metaphor unless identity fields are read/write state with explicit effect paths.

**Perceive → appraise → remember → feel → decide → act → reflect** is better for causal instrumentation because it implies a sequence and candidate transition points. It hides concurrent/continuous processing, perception/action feedback in the environment, and necessary backward paths: retrieved memory should shape appraisal and decisions; outcomes should update memory, trust and future policy; affect may bias attention and retrieval before an explicit “feel” step. It also risks duplicating “appraise” and “feel” where the system has one numerical update, and treating “reflect” as useful even when it writes nothing behaviorally relevant.

**Better frame for V4: a state-transition graph with temporal lanes.** One authoritative state schema holds world/belief estimates, episodic and semantic memory, active goals/intentions, affect/relationship, identity/constitution, and uncertainty/provenance. Event handlers, candidate/action selection, and learning update that state through logged transitions. A fast reflex lane, foreground interactive lane, and asynchronous deliberative/consolidation lane compete under an explicit control policy. “Workspace” is a bounded arbitration/broadcast mechanism only if competing modules can propose content and consumption is measurable; a per-turn dict with “workspace” in its name does not qualify. This combines Soar/ACT-R’s inspectable cycles, CLARION’s motivational/modulatory cross-links, BDI commitments, and LLM-agent memory actions without claiming any is a full account of mind.

### A testable definition of closed loop

An internal loop is closed for a particular state variable and horizon only if:

1. A specific event or outcome **writes** a named state field with timestamp, provenance, uncertainty and version.
2. A later mechanism **reads** that field to select a retrieval, goal, candidate, action or response.
3. A controlled intervention on the field (or its update) changes the predicted later behavior, while a sham/no-intervention condition does not; removing the read path removes or attenuates the effect.
4. The effect is measured at behavior level and traced through event → state diff → decision/intent → output/action → outcome. Storage, logs, verbal self-report and internal “thought” text alone do not pass.
5. Repeated and delayed trials establish persistence and time course; tests include contradictory evidence, irrelevant state changes, memory deletion/derived-state cleanup, and a model-tier comparison.

Useful designs include: a **paired state swap** between otherwise matched runs (swap only trust/mood/active goal; freeze the rest); **ablation** of the writer, reader, or transition; **counterfactual replay** with a fixed event sequence and model seed where available; **mediator tracing** of the intended state path; and factorial tests for interactions. Report the distribution of behavior deltas, latency, consistency, and unintended side effects. Keep task outcomes blind-scored when possible. Ablation alone can mislead if it also changes prompt length, retrieval opportunity, tool count, or model context. The 2025 JMLR causal-abstraction treatment formalizes interchange interventions and mediation for internal model states; 2026 Causal Memory Intervention preprint applies controlled memory-context interventions to agent responses. Both support intervention as a method, but the latter remains a preprint and not a validated general standard [14,15].

For AI_friend this means the core claim should be modest and falsifiable: “when the agent records evidence X as relationship state Y, it changes a preregistered later behavior Z through path P, and resetting/swapping Y changes Z in the predicted direction.” That establishes causal organization and continuity in software. It does not establish subjective feeling.

## 3. State of the art

1. **Best architectural reference for the whole agent: CoALA plus BDI control concepts.** CoALA separates internal memory actions from environment actions and puts both under a repeating decision procedure; BDI makes goal adoption and continued commitment explicit. Combined, these are a better implementation vocabulary for a persistent LLM mind than three vague layers. They do not solve affect or identity by themselves [5,10].
2. **Best workspace reference: LIDA.** Its attention-codelet competition and global broadcast make a concrete hypothesis about shared access among perception, memory and action. Implementation coverage is partial, and “global availability” needs direct consumer-path evidence [3].
3. **Best tested memory-and-reflection proof of concept: Generative Agents.** The 25-agent, two-day sandbox and 100-set believability comparison show sizable effects for an integrated memory/planning/reflection package. Its human rating and social simulation measures do not establish stable agent identity over weeks [7].
4. **Best recent memory evaluation direction: incremental, multi-capability and provenance-aware tests.** MemoryAgentBench evaluates four competencies over multi-turn accumulation; 2026 AfterDeleteBench compares exposed/deleted and never-exposed matched agents behaviorally. Infini Memory is a 2026 preprint with reported 64.7% MemoryAgentBench score. These support broader and causal evaluation, while benchmark scores remain task-specific [10,11,13].
5. **Best explicit affect/modulation reference: CLARION, with a narrow robotics demonstration.** Its four subsystems and dual representation can inform state and controller boundaries; the 2025 table-clearing experiment remains small and domain-specific [4].

## 4. Where our design is weak or out of date

The project’s allowed V3 architecture description names a ten-stage foreground pipeline (current architecture, “Pipeline”) and separate subconscious process. The live implementation confirms that broad shape at `backend/app/cognitive/pipeline.py:814-910`: it appraises from a state snapshot, updates state, decides, commits an `ActionIntent`, generates and validates output, then emits `reflection_needed`. This is a real loop scaffold. It is not proof that each purported process is causally functional.

## 5. Limits

- `SCIENCE` — There is no accepted, complete cognitive architecture that explains how human reactive, deliberative, reflective, affective and identity processes jointly produce a mind. Architectural comparisons reveal useful mechanisms, not one settled answer.
- `SCIENCE` — Predictive processing, workspace theories and other neuroscience accounts make competing empirical claims; their scope and interpretation remain contested. Evidence from human brain experiments cannot be directly transferred to an LLM system.
- `UNKNOWABLE` — Under the project’s stated operational scope, whether internal state is accompanied by subjective feeling cannot be settled by persistence, complexity, verbal report or behavioral resemblance tests.
- `ENGINEERING` — Whether a given state field changes a later output is testable by replay, state swaps, ablations and provenance. Several current paths are not yet exposed as a single causal trace.
- `RESOURCE` — Long-horizon, many-condition trials across local small models, larger local models and local Claude Code require inference time and model availability. Hardware limits affect scale and latency, not whether the causal question can be specified.
- `SCIENCE` — Human-likeness, believability, behavioral coherence and mind-organization are different targets. No literature score or single benchmark maps them onto one agreed quantity.

## 7. Open questions for the owner

1. Is V4’s primary evaluation target **causal continuity/coherence**, human-rated realism, autonomous initiative, or a weighted combination? Evidence does not make those interchangeable.
2. What is the intended boundary between a persisting “self-model” and persona constraints? For example, should it contain beliefs about what the agent can do, what it remembers, current commitments and uncertainty, or only slow traits and relationship state?
3. Which V4 state variables may change autonomously, and what evidence/corroboration is sufficient to commit a change without external review? DR-020/DR-038 frame the issue, but the correct threshold is a product/design choice.
4. Should a workspace be a literal competitive broadcast mechanism, a simpler bounded shared state, or neither? The literature supplies alternative implementations, not a clear winner for this system’s size and latency requirements.
