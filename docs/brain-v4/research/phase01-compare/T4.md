# T4 comparison: Codex (C), Antigravity (A), Claude (L)

Method: read the brief and all three reports; grepped the checkout read-only; searched the web. WebFetch failed on arxiv.org (certificate error) and PNAS (403), so citation checks rest on WebSearch summaries; where that is the only evidence I say so.

## 1. Agreements across all three

1. Profile, not one score, with an automatic and a human measure per dimension (C s2, A s6.1, L s6.1).
2. Persona prompt confounds Turing and believability results. Search confirms Jones and Bergen 2025: GPT-4.5 with persona 73%, LLaMa-3.1 56%, ELIZA 23%, GPT-4o 21%.
3. A Turing pass is the wrong target because D4 requires AI disclosure.
4. Causal attribution needs interventions on the state store with history held fixed: reset or clamp, counterfactual swap.
5. A prompt-only control is required (strictness differs, see s2).
6. Phenomenal experience is UNKNOWABLE; Butlin et al. is a structural audit, not a score.
7. Smallest effect of interest set before data, cited to Lakens 2022; scenario or seed is the sampling unit.
8. V3 defects NF-12, NF-16, NF-23 make state interventions uninformative until fixed. Confirmed in `docs/brain-research-v3/12-neuroscience-grounding.md`.
9. LLM judges are screening, not primary endpoints (C, L). A never discusses judge bias, a gap.

## 3. Findings only one report has

Strong:
- L: open-loop replay (replay a recorded state trajectory into a run with different user input). Tests "persists, not scripted, drives behavior" directly. Also shuffle, frozen-mean, placebo-directive controls.
- L: B4 directive-hidden arm, because state reaches the LLM only through `get_behavioral_directive()`, so state-in-words tests would pass by prompt echo (verified, s4).
- L: layer-lesion double dissociation to test the three-layer frame; claim ladder rungs 0-5; Goodhart warning on Experience as a target.
- C: state-to-action trace-completeness rate; negative-control scenarios where state should not matter.
- A: concrete defect mechanisms (trust integrity rises on hostile text; keyword-only norm check), verified despite wrong line cites.

Weak:
- A: MI/R2>=0.35 coupling, 50 ms barge-in and 300-500 ms targets: unsourced.
- A: "LLMs satisfy 2/14 Butlin indicators, RL 4/14": not in Butlin's abstract; L marks even "14" unverified. Treat as unsupported.
- A: LoCoMo "82.4% to 34.1%" and "RAG returns obsolete facts 64%": not found. The second looks like V3's `obsolete_win` relabeled as a LoCoMo result.
- C: AgentPersonaBench, REMP, and "GPT-5 59.3% at 15 min" (only a blog traces it).
- L: TOST sample sizes use an admitted approximate formula.
