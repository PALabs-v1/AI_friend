# T3 comparison: identity, continuity, portability

Reports: Codex (gpt-6-luna), AGY (gemini-3.8-flash-high), Claude sub-agent. Repo paths are under /Users/aniketsaha/Projects/PALabs/AI_friend/backend, checked read-only. Web checks done this session.

## 1. Agreements across all three

- Psychological continuity (Locke/Parfit) is the usable account, graded and not binary; branching is a known problem. Evidence: Codex s1, AGY s2.1, Claude E1-E3.
- Identity is external state plus the model, not the model alone; a swap changes the interpreter. Evidence: Codex s1, AGY "the model is the cortex", Claude bottom line 3.
- Separating state from model is sound as architecture, not as a claim of unchanged behavior. All three reject the fiction's strong premise.
- Prompt-held persona decays in long dialogue. All cite Li 2024 and Choi 2024.
- No published benchmark validates identity across a model swap (Codex s3, Claude s3).
- Needed: a per-field swap test with a no-state control and a tolerance chosen in advance (Codex move 3, Claude move 3, AGY rank 5).
- D4 disclosure must be a hard check outside learned persona state.
- Identity is split across config, JSON, SQLite and memory with no versioned snapshot or provenance (Codex gap 1, Claude 5.2, AGY 5.2).
- Subjective continuity is UNKNOWABLE.

## 2. Disagreements

   - Codex: a conjunction of state, lineage and behavioral effect, no ranking.

   - Claude: values, relationship, episodic memory, self-model, style.
   - AGY and Claude are better supported (Strohminger & Nichols observer judgments). Only Claude states the limit: these are lay judgments about people, not tests of swapped models.

   - AGY: says honest self-disclosure is "enforced deterministically" under D4. False.

3. Swap tolerance.
   - AGY: fixed delta BFI-2 <= 0.15, boundaries 100%.
   - Codex: pre-registered, no known threshold.
   - Claude: pre-registered, relative to the system's own run-to-run noise (A/A vs A/B).
   - Claude is best supported. AGY's 0.15 has no source, BFI is self-report (Claude's L4 shows self-report and behavior diverge), and NF-37 says the persona dimensions are not validated traits.

4. Where the 95% JSON failure sits.
   - AGY puts F-005 in reflection (`learning.py:331-382`) and builds Rank 1 on "95% to 0%".
   - Repo: F-005 is `decision.py:702` (intent classifier, 63 calls) and is labeled "not a production defect". AGY is wrong on location and impact.

5. How solvable drift is.
   - AGY: "eliminates drift", CharacterEval >0.85, split-softmax -64%.
   - Codex and Claude: data is thin (18 turns or 100 rounds, prompted persona only). Better supported; AGY's figures failed checking (s5).

6. Choi et al. model count: Codex "ten", Claude "nine". Abstract says nine. Codex is wrong, minor.

7. Anchoring fix: AGY wants a recency re-anchor block; Claude wants scheduled probes then retrieval re-anchoring; Codex wants only a suite. No report has evidence comparing variants. Claude's is at least measured.

## 6. Decisions this track forces on Aniket

**D-a. Authored human backstory vs D4.** May a persona have an authored life history if it is labeled as authored background and the system says plainly it is an AI when asked?
- 1: yes, labeled, never presented as lived memory.
- 2: no human-shaped past at all.
- 3: per-deployment setting, default 2.
Recommendation: 1 with a deterministic AI-status answer. Option 2 breaks the existing `config/biography.md` authoring path.

**D-b. How D4 is enforced.** Prompt or deterministic?
- 1: prompt rule only.
- 2: deterministic reflex answer for AI/human/body/past questions, relax the `action.py:721` blocklist for those turns, eval gate.
- 3: option 2 plus a post-generation check for human-past claims.
Recommendation: 3. The current block works against D4, so this is a bug fix first.

**D-c. Swap tolerance.** What counts as "the same one" after a swap?
- 1: fixed numeric band.
- 2: pre-registered per measure, relative to the system's A/A noise ceiling.
- 3: report only.
Recommendation: 2. Option 1 has no source; option 3 cannot gate a release.

**D-d. Swap disclosure.** Does it tell the user the model changed?
- 1: never.
- 2: only when asked, from a deterministic change record.
- 3: proactively at the next session and on request.
Recommendation: 3, fall back to 2 if intrusive. Replika evidence is a different product, so this is a product call.

**D-e. Forks.** May one export run as two live copies?
- 1: allowed, unmarked.
- 2: allowed only as an explicit fork with a lineage id.
- 3: refused while the lineage has a live writer.
Recommendation: 2 now, 3 for production.

**D-f. Decision contradictions.** `reset_persona.py` vs DR-033, and `LEARNING_REVIEW_REQUIRED=True` vs DR-020 (nothing approves, so the adaptive persona never changes by default).
- 1: keep both as documented exceptions.
